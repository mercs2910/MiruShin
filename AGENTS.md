# MiruShin TV

- Спілкування з користувачем — українською. Мова застосунку — російська.
- Перед змінами прочитайте `README-TV.md` і план у `docs/plans/`.
- Основа: MiruShin 2.9.24. Робоча гілка: `fix/android-external-players`.
- Тестовий пакет: `com.emp0ry.mirushin.diagnostic`, назва MiruShin Test.
  Поточний офіційний застосунок і його дані зберігайте для порівняння.
- Вибір плеєра Android є локальним; не додавайте його до синхронізованого
  блоку налаштувань Mac/Google Drive.
- Зовнішнє відтворення не повинно запускати внутрішній відеодекодер чи
  декодер мініатюр. Використовуйте чинну логіку прогресу й маркерів.
- Відновлюйте контрольні точки лише у відповідний обліковий запис, не
  перезаписуйте новіший прогрес старим. Видаляйте нативну контрольну точку
  лише після успішного запису в базу даних.
- Закриття або помилка плеєра не означає завершення серії. Для зовнішнього
  автопереходу потрібен підтверджений результат завершення.
- Не записуйте у журнали чи репозиторій токени, підписані адреси потоків,
  приватні дані застосунків і ключі підпису. Локальний ключ проєкту міститься
  в ігнорованих Git файлах Android; для CI використовується GitHub Secret.
- Спочатку перевіряйте вбудований плеєр із програмним декодуванням, потім
  Vimu, MX і Next Player. Реальні тести мають тривати довше початкового інтервалу збою
  2–3 хвилини та охоплювати вихід, повторний запуск, відновлення позиції,
  завершення серії, аварійне закриття й підтримувані пропуски.
- У звітах окремо вказуйте перевірку коду, результат автоматичних тестів,
  створення APK, встановлення та фактичне відтворення. Не називайте патч
  виправленням ривків до перевірки на приставці.
