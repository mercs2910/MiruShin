# Перенесення виправлень синхронізації на Android

3 листопада 2026. Гілка `fix/android-external-players`.
Патчі взято з `.claude/worktrees/macos-mac-mini/handoff/`, повний опис —
`PROMPT-android-agent.md` у тій самій папці. Обидва спершу пройшли
`git apply --check` і застосувалися без конфліктів.

## Зміни

- `6b400fd`: `1-stop-title-metadata-loop.patch`. Назва, популярність,
  кількість уподобань і теги AniList можуть оновлюватися локально без
  створення повної операції `metadata`. Інші зміни, наприклад опис,
  залишаються синхронізованими. Дані в Drive цей патч не видаляє.
- `a46ee4b`: `2-upload-before-exit.patch`. Після збереження позиції та
  зупинки звичайної синхронізації відправляються лише позиції цього
  пристрою й черга бібліотеки, перед закриттям бази. На Android одна
  спроба без діалогу; система все ще може завершити процес раніше.
- `89f8757`: тестова програма вміє прочитати лише агреговані лічильники
  своєї SQLite-бази. Офіційний пакет цю команду ігнорує. Адреси потоків,
  облікові дані, назви та вміст операцій не виводяться.
