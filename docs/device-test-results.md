## Вбудований MPV, програмне декодування

- Відтворення тривало понад п'ять хвилин реального часу. Коротка ручна
  пауза була на першій хвилині. Старе зависання сервісу Realtek не повторилося:
  його потоки залишалися без навантаження, повідомлень RTKC2Vdec про порожню
  чергу не було. Це підтверджує обхід проблемного апаратного шляху в цьому тесті.
- PSS застосунку: 188 839 → 248 562 КБ; температура CPU приблизно
  59.7 → 62.3°C, системний thermal status = 0. Програмне декодування
  навантажує CPU сильніше: проміжні показники 162–170% із максимуму 400%.
- Пропуск вступу підтверджений журналом: 1:28 → 2:58, маркер 1:29–2:58.
- Після нормального виходу серія 11 отримала позначку Continue, а не
  «переглянуто». Повторний запуск завантажив `savedSeconds=423` (7:03)
  і почав зі збереженої позиції.
- Після перемотування до кінця підтверджено автоматичний запуск серії 12
  з тією самою озвучкою та якістю. Окремий автоматичний пропуск кінцівки
  цим перемотуванням ще не підтверджений.
- Системні інтервали оновлення поверхні не є виміром кожного кадру відео.
  Звук інструментами дистанційного керування не прослуховувався; повну
  суб'єктивну плавність звуку й зображення цей звіт не засвідчує.
- Чинний експорт діагностики відкриває Android file chooser, якого на цій
  приставці немає («Збереження скасовано»). Використано системні показники
  та відфільтрований журнал, без адрес потоків.
