# Відкриті Android-плеєри для MiruShin TV

Перевірено 3 листопада 2026 року. Мета — Android TV, керування пультом,
збереження серії й позиції, можливість обійти проблемний декодер Realtek.
Підтримка функції в документації ще не доводить її роботу на цій приставці.

| Проєкт | Чим корисний | Обмеження для нашого випадку |
| --- | --- | --- |
| [Next Player](https://github.com/anilbeesetti/nextplayer) | Сучасний інтерфейс, окремий Android TV режим, програмне декодування, швидкість, мережеві сховища. Відкритий GPL-3.0. | ASS/SSA має обмежене оформлення. Інтеграцію позиції та перемотування треба перевіряти на пристрої. |
| [Just (Video) Player](https://github.com/moneytoo/Player) | Невеликий плеєр на Media3, Android TV, AFR, медіасеанс, HLS/DASH, без реклами. | FFmpeg у README стосується насамперед аудіо: це не доказ програмного H.264, потрібного для обходу нашого збою. |
| [mpv-android](https://github.com/mpv-android/mpv-android) | Апаратне й програмне декодування, libass і подвійні субтитри, багато параметрів зображення. ## Перший кандидат: Next Player

Установлено офіційний **0.20.0** для `armeabi-v7a`. Його
[Player API](https://github.com/anilbeesetti/nextplayer/blob/main/PLAYER_API.md)
сумісний із MX VIEW intent: початкова позиція, заголовки, результат виходу,
позиція й тривалість. `decode_mode=2` запитує програмне декодування;
результат також повідомляє фактичний режим. Окремо підтримується швидкість.
Це найпряміший кандидат для вже підготовленого адаптера MiruShin.

[Офіційний реліз](https://github.com/anilbeesetti/nextplayer/releases/tag/v0.20.0):
SHA-256 завантаженого APK збігся з digest ресурсу GitHub:
`b762022b9c09c810ac492cb0d3197f34bb7f558a55c5c05fc0785d6bd8f78f94`.

Повернення позиції після звичайного виходу й періодичні контрольні точки —
різні механізми. Наш адаптер спостерігає медіасеанс обраного пакета й
зберігає контрольну точку кожні п'ять секунд, якщо плеєр публікує придатну
позицію. Пропуски залежать від наданої команди перемотування; завершення
серії не виводиться з припущення про час, потрібен явний результат.

## Можливий наступний крок

Для максимальної відповідності внутрішньому інтерфейсу MiruShin можна
окремо дослідити вбудований Media3 або LibVLC. У репозиторії вже є адаптер
`video_player`, але його Android-шлях не ввімкнено й тут не перевірено.
Це майбутня робота, а не частина підтвердженого виправлення.

Основні джерела: README та Player API Next Player, README Just Player,
README mpv-android, розділ LibVLC офіційного VLC Android. Усі посилання
ведуть до вихідних проєктів. Фактичні результати приставки записуються
окремо в `docs/device-test-results.md`.
